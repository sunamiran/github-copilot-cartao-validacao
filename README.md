# 💳 Validador de Cartões com Identificação de Bandeira

Este projeto foi desenvolvido como parte de um desafio do **Bootcamp da DIO** 💻. Ele valida números de cartões de crédito e identifica a **bandeira** (como Visa, MasterCard, Elo etc.), usando o algoritmo de **Luhn**. O código foi criado com a ajuda do **GitHub Copilot** 🤖, que auxiliou nas sugestões e acelerou o desenvolvimento.

## 🚀 Funcionalidades

- Verifica se o número do cartão é válido (usando o algoritmo de Luhn)
- Detecta a bandeira do cartão: Visa, MasterCard, Elo, American Express, Discover, Hipercard, Diners Club, EnRoute, JCB, Aura, Voyager
- Interação com o usuário pelo terminal

## 🛠️ Tecnologias utilizadas

- Node.js
- `prompt-sync` para entrada de dados no terminal
- GitHub Copilot como assistente de codificação
